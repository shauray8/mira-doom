# Doom World Model

A latent diffusion world model of **Doom** that you play in a browser, here is a little writeup on this - . There is no game engine
running: every frame you see is generated by the model, one frame at a time, conditioned on your
keyboard and mouse. On a single consumer GPU it generates **35 fps in real time**.

This repo is the Doom-only fork of [MIRA](https://arxiv.org/abs/2607.05352) (General Intuition ×
Kyutai × Epic Games) — the Rocket League dataset, its 4-player tooling, and the Modal deployment
machinery have been stripped out. What remains is the full path for one game: **preprocess → train
codec → train world model → play it.**

```
  actions ──▶ ┌────────────────────────────────────────────┐
              │  DiT denoiser (1B)  ← KV-cache of the past  │ ──▶ latent frame
              └────────────────────────────────────────────┘          │
                    frozen RAE codec (DINOv3 encoder / ViT decoder)    ▼
                                                                  video frames
```

## Quickstart — play it

Needs an NVIDIA GPU (≥ 16 GB), Python ≥ 3.10 with **torch ≥ 2.8 already installed**, `ffmpeg`, and a
HuggingFace login (`huggingface-cli login`).

```bash
./setup_inference.sh     # deps + checkpoints (~12 GB) + seed clips. Idempotent.
./infer.sh               # -> http://localhost:3754
```

Then open the page and click to play. **WASD** move · **mouse** aim · **click / Space** fire ·
**1–7** weapon · **R** new scene · **Esc** release the mouse.

First start takes ~2 minutes (the codec decoder is compiled and a CUDA graph is captured); after
that the inductor cache makes it ~20 seconds.

### Knobs worth knowing

| Env | Default | Effect |
|---|---|---|
| `MIRA_STAGE` | `wm` | `wm` = the 75k base model (keeps action control). `wm_long` = long-horizon finetune: 2× the memory, but it fires on its own and ignores weapon select. |
| `MIRA_CTX` | `0` | Context frames. `78` doubles the memory horizon to 2.23 s — **only works on `wm_long`**. |
| `MIRA_STEPS` | `6` | Diffusion steps per frame. Fewer = faster and softer. |
| `MIRA_NOISE` | `0.0` | Context noise, the drift knob. Optimal is 0 at 6 steps (0.45 is the 2-step value — it does not transfer). |
| `MIRA_WORLDKV` | `0` | Episodic memory (yaw-cued KV bank). Implemented and cheap, but measured **no better than off** |

## Training

```bash
./setup_training.sh                  # deps + DINOv3 + an 8-shard trial slice
DOOM_SHARDS=0 ./setup_training.sh    # the full dataset (~950 GB source, ~21M frames)
```
It prints the three commands to run, in order. The configs already default to Doom geometry
(384×512, 35 fps, the 13-key action vocabulary), so they only need paths:

```bash
# 1. Codec — frozen DINOv3-L/16 encoder + ViT decoder. The only stage that needs DINOv3 weights.
export RS_DINO_WEIGHTS_DIR=./dino_weights
python3 scripts/train_codec.py \
    dataset.train_index=data/doom_mira/train dataset.test_index=data/doom_mira/test \
    run.batch_size=4 run.steps=60000 run.output_dir=ckpts/doom_codec

# 2. Single-player world model — this is the one you play. The codec ships frozen inside it.
python3 scripts/train_world_model.py \
    dataset.train_index=data/doom_mira/train dataset.test_index=data/doom_mira/test \
    model.architecture.config.codec_checkpoint=ckpts/doom_codec/checkpoint-XXXX/checkpoint.pth \
    run.batch_size=8 run.steps=250000 run.output_dir=ckpts/doom_wm

# 3. Two-player world model — warm-started from step 2, optional, ~40k steps.
torchrun --nproc_per_node=N scripts/train_world_model.py model=multi_wrapper_world_model \
    dataset.n_players=2 \
    dataset.train_index=data/doom_mira/train dataset.test_index=data/doom_mira/test \
    model.architecture.config.wm_config.codec_checkpoint=ckpts/doom_codec/checkpoint-XXXX/checkpoint.pth \
    run.finetune_from=ckpts/doom_wm/checkpoint-XXXX/checkpoint.pth \
    run.batch_size=4 run.steps=40000 run.output_dir=ckpts/doom_wm_mp
```

Evaluate offline:

```bash
python3 scripts/eval_world_model_offline.py ckpts/doom_wm/checkpoint-XXXX/checkpoint.pth
```
